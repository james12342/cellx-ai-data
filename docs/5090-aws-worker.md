# AWS 页面 + 家中 RTX 5090

## 使用

打开 https://app.cellaidata.com/agent/ ，进入视频生成节点：

1. 上传清晰的经纪人正面照片。
2. 在“生成视频”窗口选择 **RTX 5090 数字人口播**。
3. 选择人像照片，填写中文或英文口播，选择配音和画幅。
4. 点击“使用5090生成口播”。页面显示排队、生成、完成，可以预览和下载。

使用现有管理令牌访问；“访问令牌 / Access token”按钮适用于不支持浏览器 prompt 的环境。令牌仅存于当前会话，不放入 URL。刷新后已有任务通过“继续查询”恢复，不必再次生成。

首版：一张照片、100字以内、实际音频最长20秒。文字配音调用 Edge 在线语音；照片推理、画幅处理和 MP4 编码全部在5090执行，不调用收费视频模型。模型质量取决于 SadTalker，5090提速不代表嘴型更自然。

另外提供 **RTX 5090 数字人开场＋图片讲解 / Presenter + photos**：上传2–10张照片，选择其中一张人像，设置15–300秒、画幅和声音，再生成分镜或填写逐镜口播。时长可输入任意整数，例如60、75、120；300只是上限，不是默认值，已有项目时长不变。选定人像先出场，其他照片保持原顺序且全部使用；人像开场最长20秒。新模式的配音、实际测时、嘴型、字幕与整片合成都在5090执行；AWS只做派单、存储、页面展示和可选OpenAI文案调用。经济广告仍为15–60秒，纯人像仍最多20秒，付费供应商范围不变。

### 在混合模式里编辑口播

视频模式/时长下面就是“数字人开场＋图片讲解”卡片。在人像、配音选项下方的 **本次视频要说的话 / Narration to submit** 编辑：第1镜明确标为“数字人开场口播”，后续“图片讲解”带对应文件名和顺序。这里显示的是当前实际提交文字；混合模式不再同时展示另一个独立总口播编辑框。尚未采用的AI草稿只读预览，点击“使用这份AI草稿”才替换手写稿；“保存广告方案”后重开保留。

纯人像、混合模式和经济广告分别保留切换前的口播草稿；重新打开窗口回到顶部。逐镜文字中的换行仍归属于该镜头，不会多切出一张图片。旧稿文字和分镜缓存不一致时，以实际提交口播显示，避免看到旧分镜、提交另一稿。旧版页面刷新前先保存广告方案。

编辑器修复为静态前端部署，未重启API或生成视频。专门UI测试覆盖旧稿加载、唯一可见编辑器、AI未应用/应用、编辑保存重开、多行分镜、模式来回切换及提交payload一致；纯人像/经济广告/图片分析回归通过。实际AWS页面刷新后已确认开场和逐图讲解可见。部署备份：`/tmp/cellx-before-presenter-editor-z9d2qvb8`、`/tmp/cellx-before-presenter-editor-qkg7347h`。

分镜草稿在AWS只估算时长，实际语音测时在5090生成时进行；语速只允许0.88–1.12倍调整。配音校正允许目标的2%或3秒（取较小值）的误差，并在300秒上限处进一步收紧为0.1秒，最终编码只允许微小容器误差。不会通过长静音或切掉语音凑时长。长稿分句生成字幕，避免整段占满屏幕；长任务扩大了文字预算、模型输出预算与处理超时，租约仍持续续期。图片信息不足时明确提示，不为凑时长编造房源信息。

未修改的AI稿如果测时仍不合适，5090把逐镜实测时长回传AWS，最多调用两次OpenAI修订文字，然后在5090重新配音测时；AWS不执行TTS或视频合成。服务端签名绑定完整文字、图片顺序、人像、目标时长和声线，手写稿、改稿或旧参数签名不匹配时不自动改写。修订稿保存在任务effective_scenes，原options.scenes保留。失败显示实测开场/总长/目标/调速结果，并提示使用“AI写分镜口播”和“使用这份AI草稿”或手工编辑。修订失败不无限调用API。

本版新模式不加背景音乐。人工编辑口播及ChatGPT手工文案路径保留。已有经济广告/照片轮播模式保留原路径，其中照片剪辑仍在AWS执行；付费视频选项仍按其原有供应商运行。

## 架构和运行

- AWS：`/opt/cellx-extension-api/gpu_jobs.py`，SQLite队列与私有文件存储，API状态和结果展示。新模式不在AWS启动FFmpeg、模型或PyTorch。
- 队列：`/opt/cellx-extension-api/private-gpu-jobs/queue.sqlite3`，同目录存人像副本和成片。
- 5090：`C:/Users/User/CellAI-5090/worker/gpu_portrait_worker.py`，复用独立venv和SadTalker。
- Windows计划任务：`CellAI-5090-GPU-Worker`，SYSTEM身份，开机启动，进程失败重试，不依赖本机SSH窗口或用户登录桌面。
- 5090主动通过HTTPS每5秒领取任务，不开放公网端口。机器关机、休眠或断网时不能生成；已排队任务保留。
- 专用worker token独立于网页管理令牌；不把OpenAI、Runway或AWS管理凭据发到5090。密钥值不写日志。
- 本地测试页7862及原17862 SSH转发仍可用；共享推理文件锁保证同一时间只运行一个推理进程。

## 恢复与限制

任务请求ID去重；内容改变不能复用已存在ID。领取租约180秒，每20秒心跳；工作机失联会终止本地处理，租约过期后重新排队，最多3次。过期租约不能覆盖新结果；上传重试不会重复生成已完成任务。明确的输入错误直接失败并显示原因。

AWS数据在服务重启后保留。worker异常退出由计划任务重启；网络错误在进程内重试。运行日志：`C:/Users/User/CellAI-5090/worker/worker.log`（轮转），每次推理日志在`worker/jobs/<任务ID>/<尝试ID>/render.log`。

AWS首版最多100个任务，成片存储软配额420MB，单片最多160MB。混合模式提交体最多512KB，其他视频模式仍为32KB；页面只发送当前模式需要的分镜资料，其他模式草稿保留在工作流。页面可删除已完成/失败的任务。5090测试产物保留在worker/jobs，尚未实现自动清理、用户间配额隔离、取消任务或多GPU调度。现有页面及接口仍是管理员功能，不宜直接作为无鉴权公共服务。
