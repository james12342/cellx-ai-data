# 经济广告制作

在模板库导入 **Economy Product Ad · 经济广告**，或打开现有 Video Generation 节点，选择 **Economy Ad / 经济广告**。

1. 上传 1–10 张 PNG、JPEG 或 WebP 商品图。
2. 填写已确认的产品信息。点击“AI 写分镜口播”生成草稿，核对后点击使用；也可以自行填写口播。
3. 每行口播对应一个镜头，图片按上传顺序轮换。支持 1–10 个镜头，每行最多 240 字符，总计 1200 字符。
4. 选择中文/英文男声或女声，也可以选择仅字幕配乐。中文为主的口播会自动将英文声线匹配为同类型中文声线，以免语音服务返回空音频。
5. 填写品牌名称、片尾提示，设置 15–60 秒目标时长和背景音乐。
6. 生成完整广告，然后预览、下载 MP4。画面以 720p 竖屏、横屏或方形输出。

已有成片时可以勾选“使用当前已生成的视频作为首镜头”。复制现有文件参与合成，不发起新的 AI 视频请求，首镜头原声音不保留，由广告口播和配乐替代。较短视频会循环至该镜头结束。其余镜头使用商品图片。

## 成本与时间轴

经济模式不调用付费视频生成模型。AI 写稿沿用服务器 OpenAI 配置，单独按其用量收费。配音使用 Edge TTS 在线服务，发送口播文本；它依赖网络与上游可用性。合成仍占用服务器资源。

字幕使用配音返回的 SRT 时间轴；不使用语音时按文案长度分配显示时间。配音较长时成片可适当超过目标时长，但不超过 60 秒；超过上限会要求缩短口播。配乐修改使用保留的无背景音乐版本，避免重复叠加。

## 后台

- `economy_videos.py`：输入校验、任务去重、配音、时间轴、FFmpeg 图片运动与剪辑、字幕、配乐。
- `product_briefs.py`：`purpose=narration` 生成可审阅口播，复用已有产品图分析和密钥管理。
- `promo_videos.py`：现有私有任务、预览、下载和删除入口。
- `ECONOMY_TTS_PYTHON` 默认 `/opt/cellx-economy-venv/bin/python`；独立环境安装 `edge-tts==7.2.7`。
- 系统需要 FFmpeg、ffprobe、fonts-noto-cjk。合成与照片轮播共用单任务信号量，FFmpeg 限制线程，子进程使用现有低权限工作账号。
- 服务重启中断的经济任务会标记失败，不自动重跑。临时工作目录在任务结束后清理。

## 参考项目

流程借鉴 [MoneyPrinterTurbo](https://github.com/harry0703/MoneyPrinterTurbo)，审阅版本 `2ee81cfe41c7192dcc7b2b8ad1aae5ba17b5b399`：脚本 → 配音 → 字幕 → 素材 → 合成。

本项目新增实现适配现有私有素材与 FFmpeg 架构，没有整包引入其 Streamlit、MoviePy 或 Whisper 环境，也没有复制其源码。上游项目许可证为 MIT；后续复制其代码时需携带原版权与许可证。

本版提供商品图剪辑和已有视频混合，不包含库存素材搜索、自动发布或新的视频模型调用。

## 验证

运行 `test_economy_videos.py` 验证时长、素材、字幕转义、配音时间轴、任务去重及工作锁释放。运行 `scripts/test_economy_video_ui.cjs` 验证界面与请求。

`scripts/smoke_economy_render.py` 在 Linux 环境执行真实 Edge 配音及 15 秒 FFmpeg 合成，使用合成测试图片；可传入现有 MP4 路径测试横屏混合模式。部署脚本 `scripts/deploy_economy_videos.py` 带在线文件哈希检查、运行中任务保护、备份和失败回滚。
