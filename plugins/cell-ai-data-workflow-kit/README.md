# Cell AI Data Workflow Kit

Cell AI Data Workflow Kit is a Codex plugin package for building Cell AI Data / CellX automation demos.

It includes ready-made workflow JSON templates, reusable scripts, and a Codex skill that helps users create workflows for real estate listing alerts, AI property analysis, Gmail delivery, e-commerce research, finance analysis, website crawling, and property promo videos.

## Contents

- `.codex-plugin/plugin.json`: Codex plugin manifest
- `skills/cell-ai-data-workflows/SKILL.md`: Codex instructions for using the kit
- `workflow-templates/`: Importable CellX workflow JSON templates
- `scripts/`: Reusable helper scripts
- `assets/logo.png`: Plugin logo

## Safety

This plugin intentionally does not include API keys, Gmail app passwords, AWS private keys, or real customer contact data. Configure those values through backend secrets or environment variables.
